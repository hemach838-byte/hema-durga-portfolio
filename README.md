## 📌 Project Overview & Objective

The objective of this project is to design and develop a modern, responsive, recruiter-friendly personal portfolio website to showcase my technical skills, software projects, academic profile, and contact information. 

Built using pure frontend web standards (**HTML5**, **CSS3**, and **JavaScript**), the portfolio highlights my core competencies in **Java**, **JavaScript**, **HTML**, and **CSS** without relying on heavy frameworks or bloated dependencies.

---

## 🌐 Website Structure & Architecture

The website is structured into 8 cohesive, accessible sections:

1. **Sticky Navbar:** Modern glassmorphic navigation header with desktop links, mobile hamburger drawer, and real-time scrollspy active state tracking.
2. **Hero Section:** High-impact introduction displaying my name, title, brief bio, quick-action CTA buttons (*View My Projects*, *Contact Me*), social badges, and profile image.
3. **About Me:** Two-column responsive layout outlining my current academic standing at NRI Institute of Technology, passion for web development, continuous learning mindset, and career goals.
4. **Technical Skills:** Highlighting 4 foundational competencies:
   - **Java** (OOP Principles & Algorithms)
   - **JavaScript** (DOM Manipulation & Frontend Interactivity)
   - **HTML** (Semantic Structure & Accessibility)
   - **CSS** (Modern Layouts, Flexbox, CSS Grid & Responsive Design)
5. **Projects Showcase:** Interactive project grid featuring 4 real-world projects with preview cards, tech tags, direct GitHub repository links, live demos, and an expanded detail modal:
   - **PhoneShop – Phone Shopping UI**
   - **Student Management System**
   - **YouTube Clone**
   - **Image Gallery**
6. **Education:** Clean academic timeline detailing my B.Tech in Computer Science and Engineering at NRI Institute of Technology, Agiripalli (Expected 2028).
7. **Contact:** Direct channels (Email, LinkedIn, GitHub), one-click email clipboard copy, and an interactive contact form with client-side validation and mailto dispatch.
8. **Footer:** Copyright, quick links, and a back-to-top floating button.

## 🛠️ Technologies & Tools Used

- **Markup:** HTML5 (Semantic elements: `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- **Styling:** CSS3 (Custom properties/variables, Flexbox, CSS Grid, Glassmorphism, CSS Transitions & Keyframe Animations)
- **Scripting:** Modern JavaScript (ES6+, DOM Events, Clipboard API, IntersectionObserver, Keyboard Accessibility)
- **Icons & Typography:** Font Awesome 6, Google Fonts (*Inter* & *Plus Jakarta Sans*)
- **Version Control & Hosting:** Git, GitHub Pages, Netlify

---

## 🚀 Key Features

- **Responsive & Mobile-First:** Fluid layouts optimized for smartphones (320px–580px), tablets (768px), laptops (1024px), and desktop monitors (1200px+).
- **Interactive Project Modal:** Click on any project card to open an expanded view showing features, tech stack, and quick links.
- **Form Validation:** Validates required fields, checks email syntax, and provides immediate user feedback.
- **One-Click Email Copy:** Allows visitors to copy `hemach838@gmail.com` with one click.
- **Accessible & Performance-Optimized:** Semantic HTML, ARIA attributes (`aria-expanded`, `aria-hidden`, `aria-label`), keyboard navigation support, and lightweight assets.

## 💻 How to Run Locally

1. **Clone or Download the Repository:**
   ```bash
   git clone https://github.com/hemach838-byte/portfolio.git
   cd portfolio
   ```

2. **Open with any modern web browser:**
   - Double-click `index.html` to open directly in Google Chrome, Microsoft Edge, or Mozilla Firefox.
   - Alternatively, launch via VS Code's **Live Server** extension:
     - Right-click `index.html` -> **Open with Live Server**.

## 🚀 Deployment Guide (GitHub Pages)

To host this website live for free on GitHub Pages:

1. Push this directory to a new GitHub repository (e.g., `hemach838-byte.github.io` or `portfolio`).
2. Go to **Settings** > **Pages** in your GitHub repository.
3. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
4. Click **Save**. Within 1–2 minutes, your portfolio will be live at:
   `https://hemach838-byte.github.io/portfolio/`
